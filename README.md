# VNLS: Virtual Neuron Learning System

*Turkish name: Sanal Nöron Öğrenme Sistemi.* [*Türkçe README*](README.tr.md)

Prototype 1 (v1.3.3). A small spiking "cortex" that learns to recognize the 29 letters of the Turkish alphabet by looking at them through a simulated eye, all in the browser. Nobody tells it what a shape is. It picks up features by itself, and letter names get attached afterwards.

## Development and AI assistance

VNLS was developed using an AI interface (Anthropic’s Claude) alongside several other AI models. The AI ​​assisted in writing code, comments, and documentation. The project developer handled the overall direction, algorithm design, UI design, requirements definition, and browser-based testing. Please note that the code generated by the AI ​​may contain errors. The accuracy assessment provided below is not based on an independent evaluation, but rather on the developer’s own experiments with this solution in a Node environment.

## What it does

* A 3D scene with a board, an eye, a 128×128 retina, 3000 cortex neurons and 256 name neurons. Neurons are spheres, synapses are lines, and you can click a neuron to see what it is wired to. The scene is drawn with plain WebGPU, no graphics library.
* Neurons spike. They learn with STDP, compete through lateral inhibition, and prune and regrow their own synapses.
* Names are stored as a distributed code (a pattern over several name neurons) instead of one neuron per letter.
* The eye moves. It looks once, finds the shape, turns toward it and zooms in, so the cortex always sees the letter in the middle at a similar size.
* The brain can draw. It redraws what it currently sees, or a letter whose name you give it.
* You can draw too. Switch to manual mode, draw on the board, press the letter key to teach its name.
* The interface is available in Turkish and English (Settings → Language).

## Run it

Open `index.html` in a browser that supports WebGPU. There is no build step and nothing to install. It also works on GitHub Pages or from a local web server (WebGPU needs a secure context: `https`, `localhost` or `file://`).

Recent Chrome and Edge have WebGPU; for Safari and Firefox it depends on the version and the platform. If WebGPU is missing, the page says so instead of failing silently.

For the headless learning experiments you need Node 18 or newer: `npm run beyin-testi`.

## How well does it work?

These numbers come from Node runs with bitmap letters (29 classes, chance is about 3%), not from people drawing in the browser. Treat them as rough.

|Setup|Name accuracy|
|-|-|
|Clean letters, fixed gaze|about 48%|
|Clean letters, saccade (eye turns to the shape)|about 89%|
|Handwriting-like distortion, saccade only|about 41%|
|... plus zoom|about 51%|
|... plus learning from distorted examples|about 55-57%|

Two things we tried that did not help: giving the cortex more neurons (1500, 3000 and 6000 all landed at 55-59%), and pooling the retina output.

For comparison, a plain one-hidden-layer network trained with backprop on the same distorted images reached 93% from 2500 examples. So if raw accuracy is the goal, this is not the way to get it. The point of VNLS is the learning style: unsupervised, spike-based, no backprop.

## What it is not

It is brain-inspired, not a brain simulation. The learning ideas (spikes, STDP, competition, rewiring, distributed codes, eye movement) are close to the biology. The architecture and scale are not: one cortex layer instead of a hierarchy, 3000 neurons, a camera model instead of a real retina, and the eye movement is computed by plain code rather than by a neural circuit. A second cortex layer that learns strokes, curves and corners is the obvious next step; the current one tops out around 60% on handwriting-like input even with a supervised reader.

The WebGPU drawing was checked in headless Chromium on a software adapter, with the frame read back from the GPU. Putting the frame on a real screen with a real GPU is standard WebGPU, but it was not verified on every browser.

## Using the panel

* **Pause** stops automatic trials and learning. Drawing by hand and teaching names keep working while paused.
* **Mode** switches between automatic (random letters) and manual (you draw).
* **Speed** has slow, fast and ultra. Ultra uses a time budget per frame, so the page does not freeze.
* **Settings** has sliders for the learning parameters. Some apply at once, some on "Reset brain", the size ones after a page reload. Everything is stored in the browser.
* The panel can be dragged by its title, resized from the corner and collapsed. Double-click the title to reset it.
* With the mouse over the scene: W/A/S/D move the camera, Q/E go down and up, Shift is faster. With the mouse over the panel, letter keys teach names in manual mode.

# Algorithm Used

This project learns two distinct things: shapes (unlabeled) and the names of those shapes (when the name is provided). I am implementing the code, using default parameter values.



1\) Learning shapes (cortex, unlabeled)



Each presentation of a character lasts 50 steps. In each step:



Retina: Each bright pixel fires a spike with a probability equal to its brightness multiplied by 0.3. Additionally, every pixel maintains a "trace": trace = trace × 0.9 + spike. A pixel that has spiked recently carries a high trace value.

Input: Each cortical neuron has 150 synapses, with each synapse connected to a retinal pixel. The input to a neuron is the sum of the synaptic weights of the pixels that have spiked.

Neuron: v = v × 0.9 + input. If v exceeds a threshold (8 + adaptation threshold + homeostasis component), the neuron fires; v is then reset, the neuron enters a 3-step refractory period, and its threshold increases slightly.

Lateral inhibition: When a neuron fires, 6 × (number of firing neurons) is subtracted from the v value of all other neurons. This ensures that only a few neurons "win"—a form of competition.

STDP: When a neuron fires, each of its synapses is updated as follows: Δw = 0.01 × (pixel trace − 0.1) × (1 − w). Pixels that were active recently are strengthened, while inactive pixels are weakened. Consequently, the neuron develops into a template for the shape that triggered its firing.



After the presentation:



Homeostasis: The threshold of a neuron that fires more frequently than the target firing rate (5%) is increased, while the threshold of a neuron that does not fire at all is decreased. This ensures that no single neuron "gobbles up" everything, and no neurons become "dead" (inactive).

Rewiring: The winning neuron discards its weakest synapses (up to 2) and establishes new ones connected to a pixel that was highly active during that specific presentation.

Normalization: The total weight of each winning neuron is scaled to a fixed value (12), meaning that as some connections strengthen, others weaken.

2\) Learning names (second layer)



There are 256 "name neurons." The name of each letter is represented by a code consisting of 8 randomly selected name neurons. When a letter key is pressed:



The connections between the currently firing cortical neurons and the name neurons associated with that letter’s code are strengthened (+0.1 × number of firings).

Connections to name neurons not included in the code are slightly weakened (−0.003 × number of firings). This opposing term ensures that the codes remain distinct from one another.

The connections for each neuron are normalized so that their sum equals 1.



The brain then repeats this process 6 more times, encountering the same drawing with slight shifts, rotations, and scaling.



Generating a response: An activity pattern emerges across the name neurons, driven by their connections to the firing cortical neurons. The contribution of the neurons associated with each letter’s code is calculated; the letter with the highest contribution is the chosen response.



Honest notes

Cortical learning is unsupervised (label-free), but the "name layer" requires a "teacher" (someone to provide the name).

STDP (Spike-Timing-Dependent Plasticity) is simplified here: it considers the input trace following a firing event, rather than utilizing a full spike-timing curve.

Normalization and homeostasis are engineering shortcuts inspired by biology. Lateral inhibition is implemented as a single numerical value rather than through dedicated inhibitory neurons. The architecture follows the paper by Diehl \& Cook (2015).
